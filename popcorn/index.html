🎯 수업 목적

컴퓨터가 0과 1로 숫자를 표현하는 원리(이진법)를 팝콘 게임을 통해 배웁니다.

  1. 모드 선택: 치즈맛(1~60) 또는 카라멜맛(61~120)을 선택합니다.
  2. 팝콘 튀기기: 선생님이 [팝콘 튀기기 🍿] 버튼을 누르면 팝콘 속 십진수가 등장합니다.
  3. 학생 활동: 학생들은 이진수 카드(64, 32, 16, 8, 4, 2, 1)로 십진수를 만듭니다.
  4. 정답 공개: [정답 뒤집기 🔓] 버튼을 누르면 맞았을 때만 카드가 뒤집히며 정답 폭죽이 터집니다!
